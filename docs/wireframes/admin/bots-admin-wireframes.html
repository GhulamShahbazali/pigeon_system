PigeonFly Admin — Bots / Liveness

Next.js admin panel · professional desktop dashboard · consumes /v1/admin/bots/* (SuperAdmin).
What this is: the admin controls for the content-seeding bot engine — keep the app alive with posts (images), likes, views, follows (→ notifications) and racing tournaments across 9 countries. Four tabs: Overview · Roster · Config · Content. The engine runs in the scheduler process and reads bot_config + Redis live, so every toggle here takes effect within one tick.
