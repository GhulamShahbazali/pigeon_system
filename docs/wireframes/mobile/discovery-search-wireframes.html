How this maps to the API. Find friends = GET /discovery/suggestions (popular people you don't follow yet; self + blocked excluded). People search = GET /search/users — it returns is_following so the button shows Follow or Following. Rows reuse the existing Follow (/users/:id/follow) and Message (/messages) actions — no new write endpoints. The search box on each tab lives in that tab's own wireframe: Tournaments → /search/tournaments (screen 1b), Records → /search/records (screen 2b), Chat → /search/conversations (screen 1b). Recent searches are stored locally on the device.
